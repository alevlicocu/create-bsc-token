# Create Binance Smart Chain Token
This is a basic tutorial with source code created by learning from the original Binance Smart Chain. Check it out at https://github.com/bnb-chain.

## Overview
This is the basic solidity token creation contract in Binance Smart Chain (BEP-20). This code have basic features like Renounce Ownership, Set New Admin, Taxable Token, Buy Fee up to 99%, Sell Fee up to 99%.

## Steps to create token in BSC Chain
- Go to @ https://remix.ethereum.org/ and create new file Name it with a .sol extension (e.g., NewBSCToken.sol).

- Add Token.sol with source code
Name: (Your token Name) *Write the token name inside the bracket “xxxxx”
Symbol: (Give it a symbol) *Write the token symbol inside the bracket “XXX”
Decimal: (18 is RECOMMENDED)
Note :- Total Supply: (Set your total token supply, Remember if your decimal is 18, and you want 1000000 total supply, then type in 1000000000000000000000000, cuz 1000000 + 18*0).

- Compile project with V 0.8.0 verify that the compiler is the same version in the Token.sol

- Deploy by connecting metamask.
IMPORTANT Do not navigate away you need to wait for blocks to commit AND transfer tokens to YOUR wallet.

- verify contract after 1min+ @ https://bscscan.com/ with your metamask or coin creator wallet.

- Add Liquidity on PanCake Swap for trading Recommend: BNB / NewToken for Pair.

- For the NewToken you need to paste the CONTRACT address.

**:rocket: Done!**
